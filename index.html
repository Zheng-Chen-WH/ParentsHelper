开始前先确认一下——

你有 Kimi 的 API Key 吗？

申请 Kimi API Key（约 3 分钟）

1. 打开 platform.moonshot.cn（建议复制到浏览器）
2. 手机号注册/登录
3. 进入「API Key 管理」→ 新建 API Key → 复制
4. 回到这里，点右上角 ⚙️ 设置，粘贴进去
5. 充几块钱就够爸妈用很久（按用量计费）

想更省钱还可以申请 DeepSeek 的 Key（platform.deepseek.com），在设置里切换。

请家人帮你配置

让家人把两样东西用微信发给你：① 这个 App 的链接　② 他在设置页生成的「配置二维码」图片。

第一步：用手机自带浏览器（不是微信）打开 App 链接。
第二步：打开后点下面的按钮，选微信里保存的那张二维码图片，配置自动完成。以后点桌面图标直接用。
