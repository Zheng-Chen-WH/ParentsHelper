## 为什么做这个

想给爸妈用上 AI，但现成的方案都不合适：

- **官方 App**：功能太复杂，注册登录劝退，订阅还不便宜；
- **套壳聊天工具（Chatbox 等）**：只能聊天，没法调用沙盒算账、联网搜索经常断；
- **部署一个自己的服务**：要服务器、要运维，普通人搞不定。

于是有了这个「纯前端、零后端」的方案：**一个网页，拖上 Cloudflare Pages（免费）就能跑**；
你在自己手机上填好 API Key、生成二维码，爸妈微信里长按识别一下二维码就配置完成，全程不用打一个字。

## 功能亮点

### 给爸妈的（简单）

- 💬 **大字体聊天**：字号滑块 16–30px 实时调，大按钮、单层设置页，不套娃
- 🏠 **首页快捷场景**：「查天气」「算日子」「问健康」一键提问，子女可远程定制
- 📷 **拍照识图**：药盒、说明书、商品、植物，一次最多连拍 9 张（多页合同/报价单）
- 📎 **文件上传**：PDF / Word / Excel / txt 手机本地解析；扫描件 PDF 自动转图片走识图
- ⏹ **随时打断**：输出中可停止；断网自动重试，切出去再回来接着生成
- 🌙 **夜间模式**：默认 22:00–7:00 自动开启
- 🧠 **过程可见**：AI 的思考过程、搜了什么关键词、算了什么代码，都能展开看——不糊弄老人

### 给配置者的（省心）

- 📲 **扫码配置**：你填好 Key 生成二维码，爸妈微信长按识别即完成；可选同时分享人设和快捷按钮
- 🔀 **三家 API 自由切换**：Kimi（kimi-k2.6，默认）/ DeepSeek / 千问 Qwen，聊天和识图可分别指定渠道
- 🔍 **联网搜索**：Kimi 官方工具通道（思考+搜索可并用），失败自动回退；任何聊天渠道都能借道 Kimi 搜索
- 🧮 **Python 沙盒**：官方 code-runner 云端执行优先，失败回退端侧 Pyodide（numpy/pandas/matplotlib，约 15MB 组件走缓存）
- 🩺 **一键检测**：设置页跑通 连接/模型/文本/识图/工具调用/联网搜索，失败直接显示原始错误
- 🐞 **错误报告**：一键生成（版本/UA/配置摘要/最近错误），爸妈截图发给你就能定位问题
- 🛡️ **底线提示词**：内置不可修改的真实、积极、防焦虑规则，压在所有自定义人设之上
- 🗂️ **多对话 + 收藏夹**：30 分钟内重开自动恢复现场，流式输出每 2 秒落盘防杀后台

## 快速开始

### 部署（5 分钟，免费）

> ⚠️ 一定要用 **Cloudflare Pages**，不要用 Workers：`*.workers.dev` 域名在国内被 DNS 污染。
> `*.pages.dev` 目前在国内可以直连。追求最稳可在 Pages 上绑一个自己的便宜域名（.top/.xyz 首年十几元）。

1. Fork / 下载本仓库；
2. 注册登录 <https://pages.cloudflare.com>，创建项目选「直接上传 / Direct Upload」；
3. 把整个文件夹拖进去（`pyodide/` 约 55MB，耐心等待），得到 `https://xxx.pages.dev`；
4. 以后改代码，进项目「创建新部署」再拖一次即可。

### 你的手机：配置（3 分钟）

1. 打开部署好的网址 → 右上角 ⚙️ 设置；
2. 填入 Kimi API Key（<https://platform.moonshot.cn> 控制台创建），可选 DeepSeek / 千问；
3. 点「获取模型列表」确认 Key 有效 →「保存全部设置」→「生成配置二维码」。

### 爸妈的手机：零打字（1 分钟）

1. 把二维码图片用微信发给爸妈；
2. 爸妈**长按图片 → 识别图中二维码 → 右上角「···」→「在浏览器打开」**，看到「配置已完成」即可；
3. 按顶部黄色引导条「添加到主屏幕」，以后点桌面图标直接用。

## 技术架构

```
手机浏览器（PWA）
 ├── providers.js   Kimi / DeepSeek / 千问 流式 SSE 客户端
 ├── agent.js       tool_calls 循环：官方工具 web_search / code-runner
 │                  └─ 失败回退：内置 $web_search / 端侧 Pyodide 沙盒
 ├── sandbox.js     Pyodide Web Worker（numpy/pandas/matplotlib 本地跑）
 └── app.js         对话 / 设置 / 扫码 / 检测 / 文件解析 / 夜间模式
```

- **零后端**：所有请求由浏览器直连三家大模型 API，API Key 只存在本机浏览器，不经过任何第三方服务器；
- **存储**：对话记录（含图片）放 IndexedDB，配置放 localStorage；支持「把配置固定到网址」防清理；
- **离线可用**：Service Worker 全量缓存，装到桌面后断网也能打开界面；
- **国产 ROM 适配**：扫码用纯 JS jsQR（不依赖 BarcodeDetector）、鸿蒙杀后台三重兜底、安装引导分机型文案。

## 常见问题

- **要花多少钱？** 部署免费；API 按用量计费（Kimi/DeepSeek 都很便宜，普通聊天一个月几块钱），记得在平台控制台设「余额预警」。
- **Key 安全吗？** Key 只存在你爸妈手机的浏览器里，代码开源可自查；万一泄露，去平台控制台作废重发，再扫一次码。
- **鸿蒙/小米/vivo 能用吗？** 能，这就是主要适配目标。个别浏览器阉割了部分 Web API，App 内都有兜底或明确提示。
- **GitHub Pages / Vercel 能部署吗？** 能跑，但默认域名在国内访问不稳定，给父母用不推荐。
