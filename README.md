# 智能助手（爸妈版）

给家里老人用的手机 AI 助手：打字提问、拍照识图、联网查信息、Python 算账、读文件。
纯前端网页（PWA），**不需要自己的服务器**，API 由手机浏览器直连 Kimi / DeepSeek / 千问。

## 功能

- 💬 聊天：默认 Kimi（kimi-k2.6），可切换 DeepSeek / 千问 Qwen（设置页勾选）
- 🗂️ 多对话：左上角 ☰ 打开列表，支持新建、切换、删除；⭐ 收藏夹独立入口
- 🔍 联网搜索：Kimi 官方工具通道（思考+搜索可并用、搜索词可见），失败自动回退内置 `$web_search`；任何聊天渠道都能用（借道 Kimi）
- 🧮 Python 沙盒：官方 code-runner 云端执行（优先），失败自动回退端侧 Pyodide（numpy/pandas/matplotlib）
- 🧠 过程可见：思考过程流式展示、结束后自动折叠；联网搜索关键词、沙盒代码和结果都可展开查看
- 📷 拍照识图：一次最多 9 张（多页合同/报价单可连拍），Kimi 视觉模型，可切换 DeepSeek/千问视觉模型
- 📎 文件上传：PDF / Word（docx）/ txt，手机本地解析文字（扫描件 PDF 请拍照）
- 🔊 回答自动朗读（可开关；部分国产浏览器阉割 TTS 则无声，属已知限制）
- ⏹ 输出中可点停止键中止；网络断开自动重试（退避 2s/5s/10s，回前台立即重试）
- 🌙 夜间模式：默认 22:00–7:00 自动开启，可在设置里改时间段或常开/常关
- 🔠 字体大小：设置页滑块实时调节（16–30px）
- 👴 老年友好：大按钮、单层设置页、首页快捷场景按钮（可在设置页增删改）
- 🧭 首次使用引导：自动区分「子女配置」和「父母使用」两条路径
- ✨ 智能建议：每 3 条提问自动提炼高频主题，询问是否添加新快捷按钮
- 🛡️ 底线提示词：内置不可修改的真实、积极、防焦虑规则（所有人设之上）
- 🩺 连接检测：设置页一键检测 连接/模型名/文本/识图/工具调用/联网搜索，显示原始错误
- 🐞 错误报告：设置页一键生成（含版本/UA/配置摘要/最近错误），可复制或系统分享
- 📲 扫码配置：生成二维码给父母扫（只需一次，可选同时分享人设和快捷按钮）；也支持相机扫码和从相册选二维码图片导入

## 本地试用

```bash
python -m http.server 8765
# 电脑浏览器打开 http://localhost:8765
# 手机连同一 WiFi，打开 http://<电脑局域网IP>:8765 可测大部分功能
# 注意：语音朗读和 Service Worker 需要 HTTPS 或 localhost，完整测试请部署后真机进行
```

## 部署（Cloudflare Pages，免费）

> ⚠️ 一定要用 **Pages**，不要用 Workers：`*.workers.dev` 域名在国内被 DNS 污染，手机无法访问（会解析到假 IP、连接超时）。`*.pages.dev` 目前在国内可以直连。

1. 注册/登录 <https://pages.cloudflare.com>。
2. 创建项目选「直接上传 / Direct Upload」，把本项目整个文件夹拖进去（`pyodide/` 子目录约 55MB，耐心等待）。
3. 部署完会得到一个 `https://xxx.pages.dev` 域名，先用手机浏览器直接打开测试可达性。
4. 之后改文件，进入该项目 →「创建新部署」重新拖一次即可。

备选方案（按推荐顺序）：

- **pages.dev 在你的运营商网络下也不通**：买一个便宜域名（如 .top/.xyz，首年十几元）托管到 Cloudflare，在 Pages 项目里绑定自定义域名——国内访问最稳。
- GitHub Pages 国内访问不稳定，不推荐；Vercel/Netlify 的默认域名国内基本被墙，不要用于给父母用。

## 首次配置（你的手机/电脑）

1. 打开部署好的网址 → 右上角 ⚙️ 设置。
2. 填入 Kimi API Key（<https://platform.moonshot.cn> 控制台创建）。
3. 可选：填 DeepSeek API Key（<https://platform.deepseek.com>）。
4. 点「获取模型列表」确认 Key 有效；模型名默认 `kimi-k2.6`，以控制台为准。
5. 「保存全部设置」→「生成配置二维码」。

## 爸妈手机配置（零打字）

1. 你在自己手机上：设置 →「生成配置二维码」，把二维码图片用微信发给爸妈。
2. 爸妈在微信聊天里**长按那张图片** →「识别图中二维码」→ 打开后点右上角「···」→「**在浏览器打开**」→ 看到「配置已完成」即可（配置存在浏览器本地，只需一次）。
3. 装到桌面：顶部黄色引导条按提示操作——支持时点「安装」，否则浏览器菜单 →「添加到主屏幕」。以后点桌面图标直接用。
4. 备选：App 内「扫一扫导入配置」（相机）或「从相册选二维码图片」（截图保存后导入）。

## 使用注意

- **目标设备是国产 ROM 自带浏览器**（鸿蒙/vivo/小米/OPPO 等），所有 Chrome 私有 API 都有兜底：扫码用纯 JS 的 jsQR；语音输入不可用时提示用输入法话筒键；朗读做预热+中文嗓音选择，仍不出声则是浏览器阉割了 TTS，无解，只能换浏览器或静音使用。
- **配置防丢失**：设置页「📌 把配置固定到网址」会把配置编码进网址，配合「添加到主屏幕」，即使浏览器清数据，打开图标也能自动恢复配置（华为等机型建议必做）。
- **对话防丢失**：回答流式输出时每 2 秒落盘一次、切后台立即落盘，中途杀进程也能看到半成品；设置页另有「导出/导入对话记录」做手动备份。
- **鸿蒙特别注意**（已联网查证）：鸿蒙自带浏览器把"添加到桌面"的页面跑在「轻应用容器」里（带地址栏，是官方已知限制）；且鸿蒙杀后台激进，切走再回来页面会整体重载。App 侧已做三重兜底：30 分钟内重载自动恢复刚才的对话、流式回答每 2 秒落盘、设置页可导出对话备份。如果配置仍每次都丢，检查浏览器设置里是否开了「无痕浏览/自动清理」，或改用「📌 把配置固定到网址」生成的图标。

- **数据存储在哪**：所有配置（API Key、模型、字号、夜间模式）和对话记录都存在**当前浏览器的 localStorage** 里，按「浏览器 + 网址」隔离。换浏览器、换网址（localhost vs pages.dev）、清除浏览器数据，都会丢失配置，需要重新扫码。**给父母固定用一个入口**（建议装好桌面图标后只用图标打开）。
- **安装时跳到 Edge「应用信息」页**：这是国产 ROM（小米/vivo/OPPO/华为等）的「创建桌面快捷方式」权限拦截。在跳到的页面里进「权限管理」→ 允许「创建桌面快捷方式/桌面图标」，回 Edge 重新点安装即可。换手机自带浏览器安装也可以。

- **联网搜索的实现细节**（踩坑记录，改代码前必读）：Kimi 的 `$web_search` 工具调用带 `"type": "builtin_function"`，回传 assistant 消息时**必须原样保留这个 type**，流式累积时容易丢掉（丢掉后服务端不注入搜索结果，模型会声称"没法联网"）；搜索参数里没有 query 字段，只有 `search_result.search_id`。另注意官方提示 `$web_search` 与 K2.6/K2.5 的思考模式暂不兼容，且该功能正在升级中，行为可能变化。

- **Key 安全**：Key 只存在手机浏览器 localStorage，不经过任何第三方服务器；泄露了就去平台控制台作废重发，再重新扫码配置。
- **费用**：按 API 用量计费，建议在 Moonshot / DeepSeek 控制台设置「余额预警」。联网搜索每次另收调用费。
- **语音输入**：依赖浏览器的 Web Speech API，国内部分安卓浏览器不支持；不支持时话筒按钮置灰，用输入法自带的语音键代替。朗读（🔊）不受影响。
- **沙盒**：第一次算账要下载约 15MB 组件（仅一次，之后走缓存）；单次计算 30 秒超时自动重启。
- **图表中文**：如需 matplotlib 图表正常显示中文，把一个中文字体（如 NotoSansSC，重命名为 `chinese.otf`）放到 `fonts/` 目录即可；不放则图表中文显示为方块，其他功能不受影响。
- **数据**：对话记录只存在本机浏览器，清除浏览器数据会丢失。

## 文件结构

| 文件 | 作用 |
| --- | --- |
| `index.html` / `style.css` | 界面与老年化样式 |
| `app.js` | 主逻辑：对话、设置、场景、图片、二维码 |
| `providers.js` | Kimi/DeepSeek 流式 API 客户端 |
| `agent.js` | tool_calls 循环（联网搜索 + Python 工具） |
| `sandbox.js` / `pyworker.js` | Pyodide 沙盒（Web Worker） |
| `voice.js` | 语音输入与朗读 |
| `pyodide/` | 本地托管的 Python 运行时（v0.26.4） |
| `vendor/qrcode.js` | 二维码生成库 |
